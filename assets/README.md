# Конференции.РФ — экзаменационный проект

Готовый офлайн-проект на PHP 8 + MySQL/MariaDB + HTML/CSS/JS.

## 1. Что нужно заранее
Самый простой офлайн-вариант для Windows — XAMPP:
- Apache
- PHP 8+
- MySQL/MariaDB
- phpMyAdmin

На экзамене интернет не требуется.

## 2. Установка

1. Скопируйте папку `conferences_rf` в:
   `C:\xampp\htdocs\conferences_rf`

2. Запустите XAMPP Control Panel.

3. Нажмите **Start** напротив:
   - Apache
   - MySQL

4. Откройте:
   `http://localhost/phpmyadmin`

5. Перейдите во вкладку **SQL**.

6. Скопируйте весь файл:
   `sql/schema.sql`

7. Выполните SQL.

8. Проверьте `config/config.php`.

Для стандартного XAMPP:
```php
const DB_HOST = '127.0.0.1';
const DB_PORT = '3306';
const DB_NAME = 'conferences_rf';
const DB_USER = 'root';
const DB_PASS = '';
```

9. Откройте:
   `http://localhost/conferences_rf/`

## 4. Сценарий проверки
1. Регистрация пользователя.
2. Вход.
3. Создание заявки.
4. Вход в админ-панель.
5. Смена статуса на «Мероприятие назначено».
6. Смена статуса на «Завершено».
7. Возврат в учетную запись пользователя.
8. Оставить отзыв.

## 5. Валидация
- Логин: латиница/цифры, минимум 6 символов.
- Пароль: минимум 8 символов.
- ФИО: кириллица и пробелы.
- Телефон: `8(XXX)XXX-XX-XX`.
- Email: стандартная проверка PHP.
- Все обязательные поля проверяются на сервере.
- Заявка использует выпадающие списки.
- Отзыв доступен только после завершения мероприятия.

## 6. Структура БД
- `users` — пользователи.
- `rooms` — помещения.
- `applications` — заявки.
- `reviews` — отзывы.

Связи:
- users 1:N applications
- rooms 1:N applications
- applications 1:1 reviews
- users 1:N reviews

## 9. Если БД находится на общем сервере
Преподаватель/организатор обычно даст:
- IP сервера БД
- порт
- имя базы
- логин
- пароль

Тогда меняете только `config/config.php`.

Пример:
```php
const DB_HOST = '192.168.1.10';
const DB_PORT = '3306';
const DB_NAME = 'student_15';
const DB_USER = 'student_15';
const DB_PASS = 'password';
```

Сам PHP-проект при этом можно запускать локально через Apache.
